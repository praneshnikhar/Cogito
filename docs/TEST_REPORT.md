# Cogito — Test Report

## Automated tests

Run from `src/backend`:

```bash
pytest tests/ -q
ruff check app
```

Latest result: **17 passed**, Ruff clean.

| Area | What is covered |
|---|---|
| Chunking | overlap, stable content hash, page markers for PDFs |
| Embeddings | local dimension + normalization, `fit()` truncation, provider wiring |
| LLM | cited-answer shape, empty-context refusal |
| Evaluation | local judge score ranges |
| Retrieval | lexical rerank promotes the passage containing query terms |
| Query expansion | deterministic variants are unique |
| Extraction | HTML and DOCX parsing, unknown binary degrades gracefully |
| Concurrency | sync-over-async runner inside and outside a running loop |

CI (`.github/workflows/`) runs Ruff, `pytest`, and `npm run build` for the web app
on every push and pull request.

## End-to-end verification (manual / Playwright)

Performed against the Docker stack with MongoDB 8.2 + mongot, Gemini chat and
768-dim embeddings.

| Flow | Result |
|---|---|
| Upload a text/Markdown file through the UI | `pending` → `indexed` |
| Open document | metadata, summary, keywords, chunks returned |
| Hybrid search (two different queries) | different top chunks and scores |
| Cited answer | concise answer with correct document citation |
| Irrelevant question | “I could not find this in the knowledge base.”, no citations |
| Rename | document title and chunk titles updated |
| Edit content | status returns to `pending`; re-indexed by the worker |
| Delete | document + all chunks removed in one transaction; subsequent GET → 404 |
| Restart MongoDB container | healthy, data and indexes retained |

## Input validation and security

| Control | Implementation |
|---|---|
| Request schemas | Pydantic models with min/max lengths and `k` bounds (`routers/search.py`, `chat.py`, `ingest.py`, `memory.py`) |
| Upload limit | 10 MB cap; empty files rejected; document type whitelist |
| Write auth | `X-Admin-Token` / Bearer token, constant-time compare (`deps.py`) |
| Token exposure | Next.js server-side proxy injects the token; it is never shipped to the browser |
| Rate limiting | 60 requests/minute per query prefix; HTTP 429 with `Retry-After` |
| Secrets | `.env` is gitignored; API keys are not committed |
| Error handling | 400/401/404/413/422/429 surfaced as readable UI messages |

## Known gaps

- No automated database integration tests in CI; E2E is manual/Playwright.
  Adding a `pytest` suite against a disposable Mongo replica set is the next
  testing improvement.
- Authentication is a single shared admin token; there is no per-user login or
  row-level isolation yet.
- The local demo runs over HTTP; production would require TLS and network
  isolation.
- The plagiarism report is an institutional artifact and is not generated by
  this repository.
